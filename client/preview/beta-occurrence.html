Beta · accident occurrence

Experimental forecast for the likelihood of an accident occurring near this point inside a chosen horizon. Backed by POST /api/occurrence-risk and POST /api/risk/occurrence. Lives in its own dashed-border card with a permanent BETA pill and a yellow disclaimer footer — so it cannot be mistaken for the main SIARA risk score.

State
Provider toggle
Two endpoints power this card. UI exposes the active one as a small pill (occurrence-risk blue, risk/occurrence purple). Tap to compare results from both models in the same card.
Interaction model:
• Three horizon tabs: 30 min, 1 h, 2 h — fires a fresh request per tab.
• Gauge colour follows the same severity scale as the main risk card.
• Provider pill toggles between the two endpoints; both responses cached for 60 s.
• Disclaimer is always visible. Learn more would open a modal explaining model limitations.
• Error state offers a single retry; failures do not bubble up to the main map.
• Stat chips show confidence, sample size, last refreshed when the backend provides them.
