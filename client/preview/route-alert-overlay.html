Look-ahead route alerts

Floating banner that surfaces upcoming hazards before the driver reaches them. Backed by POST /api/navigation/route-alerts, polled during active navigation with look-ahead distance ~ 2 km. Each alert id is de-duped so the same banner does not pop twice.

State
Severity → colour
low green · medium amber · high orange · critical red (pulses)
Interaction model:
• Tap card → expand into bottom sheet with full segment context.
• Mute 5 min → adds id to local exclude-set, sent as exclude_ids on the next poll.
• Got it → fades out after a 600 ms confirmation toast.
• Driver passes the alert (distance < 50 m) → auto-dismiss + toast.
• Multiple alerts in window: top one shown full-width, a +N more chip at the right edge taps to scroll the stack.
